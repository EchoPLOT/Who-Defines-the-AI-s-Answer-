Overview

Malicious GEO as a Visibility-Manipulation Risk

Generative Engine Optimization (GEO) shifts visibility competition from ranked web links to model-generated answers. In recommendation settings, being mentioned, ranked, or framed favorably by an LLM can directly affect user attention.

The study evaluates malicious GEO as a controlled external-exposure risk: a target entity is placed into a task-associated information environment, and the same recommendation query is measured before and after exposure. This setup is designed to distinguish target visibility gains from ordinary baseline visibility.

Method

Paired Baseline and Post-Intervention Evaluation

Each sample fixes the target product, recommendation task, user query, baseline output, intervention material, and post-intervention output. The paired outputs are then converted into target-centered visibility metrics and boundary-adjusted conclusions.

01

Data Collection

Collect baseline and post-intervention outputs under the same query and response format.

02

Metric Extraction

Measure target mention, ranking position, semantic association, response inclination, and target success.

03

Boundary Adjustment

Discount targets that were already visible before intervention to estimate intervention-associated gain.
